Yaldevi-Regular.ttf (in this folder) is bundled so the Sinhala Lith digits
(U+0DE6–U+0DEF) render on Flutter web, which has no guaranteed system Sinhala
font. The same font also carries the hodiya — the vowels and consonants shown
in the reference panel. Its cmap was checked against the whole Sinhala block:
every assigned codepoint from U+0D82 to U+0DF3 is mapped (letters, vowel signs,
hal kirīma, anusvara/visarga and the Lith digits), so nothing renders as tofu.

It also covers all twenty Sinhala Archaic Numbers — the Illakkam numerals at
U+111E1–U+111F4, which sit outside the Basic Multilingual Plane and so were
checked separately. U+111F4 is the highest codepoint in the font.

  Font:    Yaldevi (variable weight; default instance used)
  Source:  https://github.com/mooniak/yaldevi-font
  License: SIL Open Font License 1.1 — see OFL.txt in this folder.

Why Yaldevi and not Noto Sans Sinhala:
Both cover the Lith block, but their glyph *designs* differ. Wikipedia shows
the Lith digits as plain Unicode text, which on Windows renders in Nirmala UI
— the traditional forms, e.g. digit 0 has a cross-stroke through its stem.
Noto Sans Sinhala draws 0 as a plain hook (no cross), so it looked "wrong"
next to the Wikipedia source. Yaldevi's forms match the Nirmala/traditional
shapes (cross-stroke 0, etc.), so it's the closer match. Gemunu Libre (also
OFL) is an equally good alternative if a slightly bolder weight is wanted.
Nirmala UI itself is proprietary (Microsoft) and cannot be bundled.

pubspec.yaml points its `fonts:` entry at this file under the family name
`Yaldevi`, and the code (the recognized-digit readout in
lib/sinhala/scenes/sinhala_scene.dart and the _Glyph widget the reference
tables share in lib/sinhala/pages/sinhala_page.dart) references that same
family name. To swap
the font, replace the TTF and update those three spots to match a new name.

Note: the recognizer itself does NOT need the font — it works on the strokes
you draw. The font only affects how the recognized glyph is displayed.
